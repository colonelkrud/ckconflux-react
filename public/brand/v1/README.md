# CK Conflux brand assets v1

Versioned production brand assets for ckconflux.com.

- `ckconflux-symbol.svg` is the canonical website/header mark.
- `ckconflux-favicon-dark.svg` is the preferred browser SVG favicon for the dark site theme.
- `ckconflux-favicon-light.svg` is available for light-background reuse.

Keep `/brand/v1/` immutable after release. A future brand revision should be published under `/brand/v2/` so long-lived cache headers remain safe.
